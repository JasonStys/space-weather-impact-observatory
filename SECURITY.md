# Security and responsible use

By Jason Stys. This offline educational tool is not a publicly hosted authenticated service, a defense system or an operational space-weather monitor. No credentials, real mission-health records, remote uploads, ad services, analytics or external AI integrations are included. No guarantee of absence of unknown vulnerabilities is made.

Trust boundaries: reviewed source/bundled resources, untrusted CLI JSON, browser requests/response presentation, local exports/history, and native distribution. The running app makes no external network calls; source/help links navigate only when clicked. The loopback HTTP service is read-only, exact-host/same-origin constrained, no-CORS, with strict CSP/no inline script/eval, nosniff/frame denial/no-referrer and restricted permissions. It confines static paths including symlink resolution, rejects duplicate/unknown/oversized queries and fixes attachment names. It cannot browse general local files, receive uploads, run commands, read history, or fetch a supplied URL.

Inputs are strict bounded JSON, not executable serialization. Object duplicates, ambiguous timestamps, nonfinite quantities and out-of-profile fields fail closed. Dynamic UI/HTML report text is escaped; SVG geometry accepts bounded numeric values only. CSV emits validated timestamps, fixed quality labels, counts and flags, not arbitrary free-form input cells. Source data hashes, canonical report hashes, parameterized SQL, serialized history-capacity transactions and immutable triggers reduce accidental drift and injection risk; hashes are not authenticated signatures. Neither checksum metadata nor local history is protected against a malicious OS user who can modify files.

Local JSON/SQLite files are **unencrypted**. Use synthetic/non-sensitive data, appropriate OS access control/encrypted disks and private backups. Do not expose the stdlib threaded server to a network or treat loopback as authentication. Host/Origin checks do not defend against a compromised browser/OS, all local malware, a resource-exhaustion attacker on the same device, or forged issue-time claims in supplied data. No rate quota, penetration-test certification, supply-chain attestation, signed/notarized binary or production SLA is promised. Dependencies are pinned and advisory scans are time-specific observations.

Downloads are unsigned; verify checksums, extract the whole bundle, use least privilege and do not bypass OS warnings or remove quarantine. Release assets are built only after exact-source Validation/CodeQL succeed and are reviewed separately from a green scan-job conclusion. No updater, browser extension, privileged driver or startup service is installed. [Release/rollback](docs/RELEASE.md).

Report vulnerabilities via GitHub's private advisory interface if available, otherwise contact the author through the public [profile](https://github.com/JasonStys) without posting exploit data or sensitive records publicly. For ordinary bugs, use a minimized synthetic issue. No real-spacecraft/radio/control interface is within scope.
